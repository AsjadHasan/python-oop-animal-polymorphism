# python-oop-animal-polymorphism
A Python OOP exercise demonstrating polymorphism and method overriding using Animal, Dog, and Cat classes with a shared speak() method.
<br>
Topics Covered
<br>

1. Object-Oriented Programming (OOP) – Creating classes and objects.
2. Inheritance – Dog and Cat inherit from Animal.
3. Method Overriding – Subclasses redefine the speak() method.
4. Polymorphism – The same method behaves differently depending on the object.
5. superclass and subclass – Understanding parent-child class relationships.
